# 隐私说明

基础人物、记录、媒体、族谱、时间线和同步功能不依赖 AI。AI 默认关闭，模型 Key 只存在于用户自己电脑或 NAS 的服务环境变量中，不进入 APK。

用户主动执行 AI 操作时，App 会提示所选资料将由本地服务发送给 DeepSeek。后端只读取完成该任务所需的记录文字、人物字段和来源元数据；不发送媒体原文件、整个资料库、配对令牌或模型 API Key。日志不记录完整私人正文、录音内容、Prompt 正文或 API Key。

AI 输出单独保存并标记为建议。模型不能删除资料、修改可见范围、发布内容、自动确认事实或直接修改人物关系。用户可以忽略结果；只有明确确认后，允许写入独立 AI 摘要、标签和已确认 claim，原始文字及原始媒体始终保留。

多模态搜索默认关闭。用户在电脑端显式启用并配置火山引擎后，后台索引会将记录/人物的最小必要文字或用户保存图片的缩略图发送给火山方舟生成向量；无缩略图时才使用对应原图。不会发送整个资料库、配对令牌、文件磁盘路径或 API Key。App 搜索页会持续显示该处理说明和索引状态。

向量检索先按当前家庭、未删除状态和用户选择的筛选条件确定允许访问的对象，再计算相似度。图片 Embedding 不用于人脸识别、身份判断、OCR 或事实推测。关闭多模态搜索后不再发起新的第三方向量调用，关键词搜索和全部基础记录功能仍可使用。

加密备份只写入用户自己的本地服务存储和用户主动选择的导出位置，不上传到项目方云端。备份排除访问令牌、配对令牌、模型 Key、临时上传和后台任务。备份密码仅用于当次加密、检查或恢复，不写入数据库和日志；日志过滤器会遮盖常见 Authorization、Bearer Token、API Key 和密码字段。

App 锁完全调用 Android 系统身份验证界面；App 只接收成功或失败结果，不读取、保存或上传指纹和面容数据。
