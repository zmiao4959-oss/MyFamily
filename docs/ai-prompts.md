# AI Prompt 与安全约束

当前 Prompt 版本：`phase5-v1`。

## 通用系统约束

- 只依据提供的私人资料，不补写未知事实。
- 区分事实、个人回忆、他人描述和 AI 建议。
- AI 输出始终是待确认建议。
- 不得删除资料、修改人物关系、修改可见范围、确认事实或覆盖原始文字。
- 不知道时明确说明不知道。
- 结构化任务只输出符合后端给定 JSON Schema 的 JSON，不输出 Markdown。

后端在每次结构化调用时动态附加对应 Pydantic 模型生成的 JSON Schema。若第一次输出校验失败，只允许一次“修复结构和字段类型、不增加新事实”的重试。

## 记录整理

输入仅包含所选记录的标题、原始文字、已有编辑文字、时间、地点、关联人物姓名、来源类型和确认状态。输出包括建议标题、摘要、标签、人物/地点候选、日期候选、claim 建议和待确认问题。原始文字不进入任何可覆盖字段。

## 人物小传

输入包含人物基础档案，以及最多 30 条与该人物明确关联的来源记录。要求逐条依据来源，未确认或矛盾信息写入 `uncertainties`。输出中的 `source_record_ids` 必须属于实际输入集合，否则任务失败。

## 采访问题

根据人物档案与已有记录生成温和、具体、一次只问一件事的问题。问题只是录音引导，不推断答案。

## 资料问答与工具

问答优先使用后端只读工具检索。允许工具包括资料/人物搜索、人物档案、人物关系、时间线、记录详情、媒体元数据和相关记录建议。`create_record_draft` 与 `suggest_relationship` 只生成建议对象，不写数据库。删除、关系修改、可见范围修改和发布能力不对模型开放。

答案中的来源记录 ID 必须来自本轮工具结果，否则任务失败。工具参数由后端再次校验，模型不能直接访问数据库。
